30c. What is the order of namespaces in which Python looks for an identifier?
a) Python first searches the built-in namespace, then the global namespace and finally the local namespace
b) Python first searches the built-in namespace, then the local namespace and finally the global namespace
c) Python first searches the local namespace, then the global namespace and finally the built-in namespace
d) Python first searches the global namespace, then the local namespace and finally the built-in namespace
Answer: c
Expl: When Python encounters an identifier (like a variable or function name), it follows the LEGB rule to resolve it. 
It first looks in the Local namespace (inside the current function), then in the Enclosing namespace (if it’s a nested 
function), followed by the Global namespace (top-level of the module), and finally the Built-in namespace (predefined 
functions like len(), sum(), etc.). So, the correct search order for namespaces is: local → global → built-in.
